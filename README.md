# AKAZI SCROLL - Salary Prediction Model

## Mission

AKAZI SCROLL is a youth employment platform connecting young job seekers with employers and government,easing job discovery, postings, and help government to track employment trends all in one place. 

This model helps to predict or estimates salary and help job seekers set realistic expectations and employers to set salary on job positions fairly using job title, location,experience level, and employment type.

## Dataset

 this dataset is used to train a model that predicts fair salaries estimated for linkedin job postings. Though this dataset is global, Akazi scroll aims to connect young african job seekers,employers and government agencies so this dataset is like a sample for african labour market salary estimation.

 link to dataset: (https://www.kaggle.com/datasets/arshkon/linkedin-job-postings)
